## 三、关键交互记录

### 3.1 图像语义审查

**提示词示例**:
```
请对这张AI生成图像进行语义审查，包括：
1. 可见主体
2. 场景描述
3. 风格类型
4. AI生成瑕疵
5. 结构完整性
6. 语义保真度
7. 质量判断（高/中/低）
8. 不确定项
```

**GPT-5.5回复示例**:
```
## 图像 1.png 审查
- 可见主体：山谷、森林、河流、雾气、远处群山
- 场景描述：清晨或傍晚光线下的高山森林峡谷景观
- 风格类型：偏photorealistic的自然风光图像
- AI生成瑕疵：局部雾气与树冠边缘有轻微融合感
- 结构完整性：山体、森林、河道和光照方向整体连贯
- 语义保真度：主体明确、空间关系合理、氛围统一
- 质量判断：高
- 不确定项：不确定该图是否需要匹配具体题面提示词
```

### 3.2 视频异常帧解释

**提示词示例**:
```
请对这个视频异常帧进行分析：
1. 是否有肉眼可见异常
2. 可能异常类型
3. 可能原因
4. 质量影响
```

**GPT-5.5回复示例**:
```
## 异常帧 62 (2.58s) 审查
- 肉眼可见异常：有
- 异常类型：局部表情变化
- 可能原因：驾驶员眨眼/说话、生成视频人脸时序不稳定
- 质量影响：中
```

## 四、采纳内容和人工修改情况

### 4.1 采纳内容

1. **语义标签**: 采纳GPT-5.5生成的主体对象、属性描述、场景关系、风格指令等正向标签
2. **缺陷标签**: 采纳手部异常、面部异常、边界融合等惩罚标签
3. **质量判断**: 采纳高/中/低质量判断作为参考
4. **异常解释**: 采纳异常帧的可能原因分析

### 4.2 人工修改情况

1. **结构化处理**: 将GPT-5.5的文本描述转换为结构化CSV格式
2. **数值映射**: 将质量判断（高/中/低）映射为数值分数（1.0/0.6/0.3）
3. **置信度调整**: 根据不确定项数量和描述强弱调整置信度
4. **一致性检查**: 检查不同图像审查结果的一致性

### 4.3 未采纳内容

1. **直接数值评分**: 不采纳GPT-5.5直接给出的数值评分，所有数值由本地代码计算
2. **排名结论**: 不采纳GPT-5.5的排名建议，排名由TOPSIS模型计算
3. **参数建议**: 不采纳GPT-5.5的参数调整建议，参数建议由短板诊断模型计算

## 五、AI工具使用边界

### 5.1 允许使用

- ✅ 语义审查和标签提取
- ✅ 异常帧解释
- ✅ 论文逻辑审查
- ✅ 代码组织和文档管理

### 5.2 不允许使用

- ❌ 直接生成数值指标
- ❌ 直接生成排名结论
- ❌ 替代本地代码计算
- ❌ 编造实验结果
- ❌ 编造参考文献

---

## 六、人工复核说明

所有AI工具生成的内容均经过人工复核：

1. **语义标签复核**: 检查标签是否准确反映图像内容
2. **数值计算复核**: 检查本地代码计算结果是否正确
3. **排名结果复核**: 检查TOPSIS排名是否合理
4. **异常帧复核**: 检查异常帧解释是否与视觉观察一致
