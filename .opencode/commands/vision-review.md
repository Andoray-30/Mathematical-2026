# 多模态审查

由 GPT-5.5 Deep Agent 执行语义审查。

## 执行者

**GPT-5.5 Deep Agent**（不是 Sisyphus/mimo-v2.5-pro）

## 输入文件

| 文件 | 用途 |
|------|------|
| `figures/pdf_pages/*.png` | PDF 页面截图 |
| `B题：.../附件1/*.png` | 原始图片 |
| `figures/video_contact_sheet.png` | 视频关键帧拼图 |
| `figures/video_frames/*.png` | 异常帧截图 |

## 审查内容

### 1. 图像语义保真度
- 生成内容是否符合题意
- 是否存在明显错误
- 视觉质量主观评价

### 2. 视频异常解释
- 异常帧的原因分析
- 闪烁/抖动/色彩突变的语义解释

### 3. 论文逻辑审稿
- 论证是否合理
- 表述是否清晰
- 是否有逻辑漏洞

## 输出文件

**`docs/vision_review.md`**

格式：
```markdown
# 多模态审查报告

## 1. PDF 题目审查
- 页面 1：...
- 页面 2：...

## 2. 图像审查
### 2.1 图像 1.png
- 语义描述：...
- 异常标注：...
- 不确定项：...

### 2.2 图像 2.png
...

## 3. 视频审查
### 3.1 整体描述
...
### 3.2 异常帧解释
- 帧 123：...
- 帧 456：...

## 4. 论文审稿意见
...
```

## 禁止事项

- ❌ 不允许直接生成数值指标
- ❌ 不允许编造题面没有的信息
- ❌ 不确定内容必须标注"不确定"
- ❌ 不允许修改 `results/` 中的数据

## 后续步骤

运行完成后，可执行：
- `write-paper` - 根据审查结果完善论文
