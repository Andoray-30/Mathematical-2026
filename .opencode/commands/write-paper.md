# 撰写论文

根据前序阶段的产出撰写完整论文。

## 前置条件

确保以下文件存在：
- `docs/problem_statement.md` - 题目分析
- `results/*.csv` - 分析结果
- `results/results.xlsx` - Excel 汇总
- `figures/*.png` - 图表
- `docs/vision_review.md` - 多模态审查（可选）

## 输入文件

| 文件 | 用途 |
|------|------|
| `docs/problem_statement.md` | 题目内容 |
| `中青杯数学建模2026规则文档.md` | 格式规范 |
| `docs/skill_to_b_problem_mapping.md` | 建模路线 |
| `results/image_scores.csv` | 图像得分 |
| `results/final_summary.csv` | 最终汇总 |
| `figures/*.png` | 图表 |
| `docs/vision_review.md` | 审查意见 |

## 执行步骤

1. **构建论证框架**
   - 核心结论
   - 证据链
   - Claim-Evidence 映射

2. **撰写论文大纲**
   - 输出：`paper/outline.md`

3. **撰写论文草稿**
   - 输出：`paper/draft.md`

4. **建立证据映射**
   - 输出：`paper/claim_evidence_map.md`

5. **准备支撑材料**
   - 输出：`support/ai_usage_log.md`
   - 输出：`support/README.md`

## 禁止事项

- ❌ 不允许编造实验结果
- ❌ 不允许出现队员姓名、学校等身份信息
- ❌ 每个结论必须对应图表或结果表
- ❌ 缺失证据必须标记 `[待补充]`

## 格式要求

根据 `中青杯数学建模2026规则文档.md`：
- 论文题目用三号黑体字
- 一级标题用四号黑体字并居中
- 二级、三级标题用小四号黑体字，左端对齐
- 论文其他内容一律采用小四号宋体字
- 行距为 1.25 倍
- 参考文献按正文中的引用次序列出

## 后续步骤

论文完成后：
1. 检查格式是否符合规范
2. 检查是否有遗漏的证据
3. 准备 PDF 导出
4. 打包支撑材料
