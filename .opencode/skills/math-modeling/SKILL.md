# 数学建模技能 - OpenCode 项目级版本

本技能是从 `math-modeling-skill-main` 提取的轻量版，专为当前 2026 中青杯 B 题项目优化。

**⚠️ 优先级说明**：
- B 题文件夹和 2026 规则文档是**最高优先级事实源**
- 本技能是**参考工具**，不能覆盖赛题和规则要求

---

## 三阶段工作流

### 阶段一：建模分析

**目标**：分析题目，确定数学模型，产出分析文档

**执行步骤**：
1. 阅读并理解题目要求
2. 为每道题确定合适的数学模型和算法
3. 记录模型对应的公式、论文引用等信息
4. 创建术语表格保持术语一致性

**产出**：
- `docs/problem_statement.md` - 题目分析
- `docs/modeling_analysis.md` - 建模分析报告
- `docs/terminology.md` - 术语表

**Model Contract（前置合同）**：
- 核心结论：一句话说明最终要证明什么
- 证据链：列出支撑结论的关键证据
- 方案评审：检查方案的可行性和完整性
- 交付规格：明确最终产出物格式

### 阶段二：代码实现

**目标**：根据建模分析编写解题代码并生成结果

**执行步骤**：
1. 检查 Python 环境和依赖
2. 按问题分开编写结构清晰的代码
3. 运行代码并将结果写入表格
4. 生成符合规范的图表

**产出**：
- `src/*.py` - 解题代码
- `results/*.csv` - 计算结果
- `figures/*.png` / `figures/*.svg` - 图表

### 阶段三：论文撰写

**目标**：根据前两阶段产出撰写完整论文

**执行步骤**：
1. 构建论证框架（Argument Building）
2. 建立 Claim-Evidence 映射
3. 按章节模板撰写论文
4. 通过自审框架检查质量

**产出**：
- `paper/outline.md` - 论文大纲
- `paper/draft.md` - 论文草稿
- `paper/claim_evidence_map.md` - 证据映射

## 评价算法（B 题核心）

### AHP（层次分析法）

用于确定主观权重：
- 构建判断矩阵
- 计算特征向量
- 一致性检验（CR < 0.1）

### 熵权法

用于确定客观权重：
- 数据标准化
- 计算信息熵
- 计算权重

### 组合赋权

结合主观和客观权重：
- 乘法归一化法
- 或线性加权法

### TOPSIS

用于综合排序：
- 正向化处理
- 标准化
- 计算正负理想解
- 计算相对贴近度
- 排序

### 敏感性分析

检验结果稳健性：
- 调整权重 ±10%
- 观察排序变化
- 计算排序相关系数

## Claim-Evidence 映射

每个论文结论必须对应：
- 代码输出的图表
- 或 CSV/Excel 中的数据

**格式**：
```
结论：XXX 图像质量最优
证据：figures/image_scores.png 排序图 + results/image_scores.csv 得分
```

## 自审清单

### 建模阶段
- [ ] 问题理解是否准确？
- [ ] 模型选择是否合理？
- [ ] 公式推导是否正确？
- [ ] 术语是否一致？

### 代码阶段
- [ ] 代码是否可运行？
- [ ] 结果是否可复现？
- [ ] 图表是否清晰？
- [ ] 数据是否保存？

### 论文阶段
- [ ] 每个结论是否有证据？
- [ ] 是否有编造内容？
- [ ] 格式是否符合规范？
- [ ] 是否有身份信息？
