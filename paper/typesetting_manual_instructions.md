# 排版操作手册

本文档指导如何使用 Word 模板完成论文排版，适用于 2026 年第八届中青杯全国大学生数学建模竞赛 B 题论文。

---

## 1. 打开模板

1. 双击 `paper/working_template.doc`（Microsoft Word 格式）。
2. 若提示"受保护的视图"，点击 **启用编辑**。
3. 若提示宏安全警告，选择 **启用内容**（如适用）。
4. 保存为 `.docx` 格式（文件 → 另存为 → Word 文档），以便后续编辑。

---

## 2. 格式规范

| 元素 | 字体 | 字号 | 对齐 | 备注 |
|------|------|------|------|------|
| 论文题目 | 黑体 SimHei | 三号 (16pt) | 居中 | 摘要页和正文首页均需 |
| 一级标题 | 黑体 SimHei | 四号 (14pt) | 居中 | "一、""二、"等 |
| 二级/三级标题 | 黑体 SimHei | 小四 (12pt) | 左对齐 | "1.1""1.1.1"等 |
| 正文 | 宋体 SimSun | 小四 (12pt) | 左对齐 | 行距 1.25 倍 |
| 页眉 | 无 | — | — | 禁止出现页眉 |
| 页码 | — | — | 页脚居中 | 阿拉伯数字，从"1"开始 |

## 4. 粘贴 Markdown 内容

源文件：`paper/final_markdown_for_docx.md`

1. 在 VS Code 或任意 Markdown 编辑器中打开该文件。
2. 全选复制（Ctrl+A → Ctrl+C）。
3. 切换到 Word 模板，定位到正文起始位置。
4. **选择性粘贴**（Ctrl+Alt+V）→ 选 **无格式文本** → 确定。
5. 逐节设置格式：
   - 选中章节标题 → 应用对应的标题样式（见第2节表格）。
   - 选中正文段落 → 设置为"小四宋体、1.25倍行距"。
6. 摘要页单独处理：队伍编号填写实际编号，选题填"B"，论文题目居中三号黑体。

---

## 5. 插入图片

图片目录：`figures/final/`

论文中引用的图片：

| 图号 | 文件名 | 说明 |
|------|--------|------|
| 图1 | `framework_flowchart.png` | 总体框架图 |
| 图2 | `topsis_ranking_bar.png` | TOPSIS排序结果 |
| 图3 | `sensitivity_analysis.png` | 敏感性分析 |
| 图4 | `video_ssim_timeline.png` | SSIM时序变化 |
| 图5 | `video_anomaly_frames.png` | 异常帧定位 |

操作步骤：

1. 在 Word 中定位到对应位置（参考 Markdown 中的 `[插入图X：...]` 标记）。
2. **插入 → 图片 → 此设备**，选择对应文件。
3. 右键图片 → **大小和位置**：
   - 宽度设为 **14cm**（页面可打印区域宽度）。
   - 保持纵横比。
   - 环绕方式：**上下型**。
4. 在图片下方添加图题：居中，五号宋体，格式为"图X 图题文字"。

## 6. 插入公式

论文包含 13 个编号公式。使用 Word 公式编辑器：

1. 定位到公式位置（参考 Markdown 中的 `$$...$$` 块）。
2. **插入 → 公式**（或 Alt+=）。
3. 逐个输入公式内容。公式居中，编号右对齐。
4. 编号格式：`(1)` `(2)` ... `(13)`，使用制表符将编号推至右端。

公式编号对应关系参见 `paper/final_markdown_for_docx.md` 中的公式块。

---

## 7. 创建三线表

表格要求使用**三线表**（仅顶线、底线、栏目线，无竖线）：

1. **插入 → 表格**，选择所需行列数。
2. 选中整个表格 → **表格设计 → 边框**：
   - 清除所有边框。
   - 添加**顶线**（上框线，1.5磅）。
   - 添加**底线**（下框线，1.5磅）。
3. 选中表头行 → 添加**栏目线**（下框线，0.75磅）。
4. 表题在表格上方，居中，五号宋体，格式为"表X 表题文字"。
5. 表内文字：五号宋体，居中。
