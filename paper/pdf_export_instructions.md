# PDF Export Instructions

## Source File

- **Input**: `paper/final_paper_draft.docx`
- **Output**: `paper/final_paper_draft.pdf`

---

## Method 1: Microsoft Word (Recommended)

1. Open `paper/final_paper_draft.docx` in Microsoft Word.
2. Go to **File → Save As**.
3. Choose location: `paper/`
4. In the **Save as type** dropdown, select **PDF (*.pdf)**.
5. Click **Save**.

Alternative path:
1. Open the .docx file.
2. Go to **File → Export → Create PDF/XPS**.
3. Click **Publish**.

---

## Method 2: Google Docs (Alternative)

1. Go to [drive.google.com](https://drive.google.com).
2. Upload `final_paper_draft.docx` to Google Drive.
3. Right-click the file → **Open with → Google Docs**.
4. Go to **File → Download → PDF Document (.pdf)**.
5. Save the downloaded file to `paper/final_paper_draft.pdf`.

Note: Formatting may shift slightly in Google Docs. Verify layout after export.

---

## Method 3: Online Converters (Last Resort)

Use only if Word and Google Docs are unavailable.

1. Go to one of:
   - [smallpdf.com/docx-to-pdf](https://smallpdf.com/docx-to-pdf)
   - [ilovepdf.com/word_to_pdf](https://www.ilovepdf.com/word_to_pdf)
2. Upload `final_paper_draft.docx`.
3. Wait for conversion to finish.
4. Download the PDF.
5. Save to `paper/final_paper_draft.pdf`.

Caution: Do not upload files containing sensitive information to third-party sites.

---

## File Naming

| Stage | Filename |
|-------|----------|
| Draft / Review | `paper/final_paper_draft.pdf` |
| Final Submission | `B2026XXXXX.pdf` |

Replace `XXXXX` with your team registration ID before submission.

---

## Verification Checklist

After exporting, open the PDF and verify:

- [ ] Page breaks are correct (no orphaned headings or split tables)
- [ ] All figures are visible and properly sized
- [ ] Equations are readable (no missing symbols or garbled text)
- [ ] Page numbers appear on each page
- [ ] Table of contents page numbers match actual pages
- [ ] No team member names, school name, or other identity information appear in the document
- [ ] Total page count is within competition limits
- [ ] File size is reasonable (under 20 MB recommended)
